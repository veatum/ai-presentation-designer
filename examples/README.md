# Примеры и showcase

Папка содержит материалы для проверки и демонстрации текущего релиза.

- `showcase/` — одна и та же колода в трёх вариантах верстки: `balanced`, `columns`, `editorial`.
- Полная матрица 3×3 может храниться в отдельном demo-архиве; основной репозиторий содержит компактный showcase из трёх вариантов.
- `content-pack.txt` — безопасный демонстрационный контент без заявленных реальных финансовых результатов.

Для внешнего API используйте собственный `.env`; ключи в репозиторий не добавляются.
