# Showcase: 3 variants of one deck

The three PPTX files use the same semantic content and the same source material; only the renderer variant changes:

- `presentation_balanced.pptx` — balanced composition;
- `presentation_columns.pptx` — column-oriented composition;
- `presentation_editorial.pptx` — editorial composition.

Each file contains 10 slides and native editable PowerPoint objects. `manifest.json` records slide count, size and SHA-256 for reproducibility.

These are technical showcase artifacts, not the team's final pitch deck. The pitch deck and demo video are intentionally left to the team.
