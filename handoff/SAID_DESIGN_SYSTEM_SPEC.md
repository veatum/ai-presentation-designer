# SAID_DESIGN_SYSTEM_SPEC.md

## Роль документа

Это handoff от визуально-контентного блока к Шейхмагомеду. Документ опирается на три входных PPTX-шаблона продукта и отдельный шаблон презентации жюри.

## Критическое разделение

**Три VK-шаблона** — входные шаблоны, которые должен уметь анализировать ваш продукт.

**ЛЦТ2026 Шаблон презентации.pptx** — отдельный шаблон для презентации команды перед жюри. В нём слайд 7 и слайды 8–11 отмечены организаторами как обязательные; слайды 12–29 предназначены для презентации решения.

## 1. VK Education

- Размер: 13.333 × 7.5 in (16:9).
- 55 слайдов.
- Theme palette: #0077FF, #FF3885, #7CEDF8, #EBF3F9, #D8FAFD, #FFEBF3, #FFFFFF.
- В самом шаблоне указано: заголовки — VK Sans Display Medium; основной цвет синий; дополнительные цвета разрешены; размер заголовков уже задан; обычный текст слева, кроме схем и таблиц.
- Типовые layouts: титульные, speaker, text blocks, section dividers, schemes/code, benefits/metrics, quote, phone mockup, screenshots, tables, timeline, charts, final/QR.
- Навигация разделов реализуется точками; число точек соответствует числу разделов.
- Таблицы: минимум лишних заливок/границ; текст слева, числа справа; единицы измерения — в легенде; акцент только по смыслу.
- Диаграммы: без лишних сеток и засечек; по возможности столбики вместо круговых; выделять цветом главное.

## 2. VK Tech

- Размер: 10 × 5.625 in (16:9).
- 54 слайда.
- Theme palette: #0077FF, #FFFFFF, #FF3885, #202020, #F7FAFE, #D6ECFF, с тёмными #001515 и #151515 в объектах/фонах.
- Основной шрифт, который реально встречается в текстовых runs: Play; также встречаются Consolas и единично Arial.
- Типовые layouts: title, divider, thank-you/QR, 3 content layouts, business cards, свободные layouts, content layouts, code, metrics/comparisons, process/timeline, charts, product/commercial examples.
- Отличительная композиция контентных слайдов: крупная визуальная область + компактный список/карточки справа; либо визитка с фото слева/справа.

## 3. VK WorkSpace

- Размер: 13.333 × 7.5 in (16:9).
- 29 слайдов.
- В theme2 зафиксирована палитра #0077FF, #00E9FF, #AAFBFF, #EDF3FC, #7C8A9A, #202020; в объектах используются также #E4E7EA, #70C3FF, #AFB8C2, #CAD0D5, #6DBCFF, #EB4250.
- Шрифт в текстовых runs — Play.
- Характерная база: тёмный фон/карточки + синие/голубые акценты.
- Типовые layouts: 6 cards 3×2, 6 numbered blocks 3×2, 8 cards 4×2, 3 wide cards, 3-column repeated items, charts, problems/challenges, CTA with QR, timeline.

## 4. Что parser должен извлекать

Для каждого layout хранить: `layout_id`, размер слайда, тип композиции, background, slots, slot roles, x/y/w/h, font family, font size, font weight, text color, fill, line, alignment, margins, max items, image aspect ratio, decorative groups, footer/logo.

**Не полагаться только на номер слайда.** Использовать `slide_layout.name` + геометрию + типы placeholder/shape. Имена layout из файлов сохранены в `TEMPLATE_LAYOUT_CATALOG.md` и `data/template_catalog.json`.

## 5. Визуальная приёмка

Генерация считается визуально принятой только если:

- layout соответствует семантической роли контента;
- геометрия существующего layout не ломается;
- текст не выходит за slot;
- изображения сохраняют пропорции;
- логотипы/футеры на местах;
- шрифты и палитра не уходят от шаблона;
- три варианта одного контента различимы, но остаются в системе шаблона;
- PPTX содержит редактируемые объекты.

## 6. Locked rule для продукта

Слайды 7–11 трёх VK-шаблонов НЕ считать глобально обязательными для жюри. Они являются обычными примерами входных layouts. Для генератора сохранять их геометрию, если выбран соответствующий layout.

## 7. Locked rule для презентации жюри

В отдельном файле ЛЦТ2026 слайд 7 и 8–11 отмечены организаторами как обязательные. Их дизайн и структура не следует заменять собственной композицией.
