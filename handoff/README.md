# Исторические и командные материалы

Папка содержит материалы handoff/дизайн-системы, использованные при разработке. Они не являются отдельной версией приложения.

Актуальная версия проекта: `7.4.2-final` (см. корневой файл `VERSION`).

Актуальная документация:
- `README.md` — запуск и переменные окружения;
- `ARCHITECTURE.md` — слои пайплайна;
- `MODELS.md` — модели и провайдеры;
- `AUDIT.md` — проверки и границы покрытия;
- `TЗ_COVERAGE.md` — сопоставление с ТЗ;
- `SUBMISSION_CHECKLIST.md` — действия перед отправкой.
